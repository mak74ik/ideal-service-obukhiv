# Комп'ютерний сервіс та майстерня «ІДЕАЛ» (м. Обухів)

Сучасний, конверсійний сайт-візитка для майстерні комп'ютерної техніки в Обухові з акцентом на високомаржинальні послуги:
- **Комплексна чистка ПК та ноутбуків** (800 грн)
- **Встановлення та налаштування Windows 10/11 "Під ключ"** (800 грн)
- **Апгрейд на SSD / збільшення RAM** (від 500 грн)
- **Апаратний ремонт, лікування вірусів, збірка ПК**

---

## 🚀 Як відкрити та переглянути сайт:
Просто двічі клацніть по файлу `index.html` або відкрийте термінал:
```bash
open /Users/yoshi/ideal-service-obukhiv/index.html
```

---

## ⚙️ Як змінити телефон, адресу або ціни:
Всі контактні дані та тарифи винесені в один зручний файл:
[`assets/js/site-config.js`](assets/js/site-config.js)

Відкрийте його в будь-якому текстовому редакторі та замініть:
- `phoneDisplay` — номер, як його бачать відвідувачі
- `phoneRaw` — номер для дзвінків (без пробілів)
- `telegramUsername` — юзернейм майстра чи каналу
- `viberNumber` — номер з Вайбером
- `address` — точна адреса або орієнтир у місті Обухів
- `prices` — будь-які ціни на послуги

---

## 🌐 Як викласти сайт в інтернет (безкоштовно):
1. **GitHub Pages / Vercel / Netlify / Cloudflare Pages**:
   - Перетягніть цю папку в сервіс Vercel/Netlify або створіть репозиторій на GitHub — сайт запрацює безкоштовно з SSL (https) за 1 хвилину.
2. **Власний домен (наприклад, `ideal-service.obukhov.ua` або `ideal-pc.kyiv.ua`)**:
   - Просто завантажте файли на будь-який недорогий хостинг у папку `public_html`.
